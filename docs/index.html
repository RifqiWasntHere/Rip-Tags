What it does

Focused on one job — clean tags without the headache.

◧

Batch clean

Point at a folder, scan recursively. Handles .flac .m4a .mp4. Skips ._ macOS junk automatically.

☑

Keep-list presets

Choose exactly what stays. Hit Recommended for essentials: title, artist, album, date, genre, cover… add the rest if you need it.

▣

Cover art — fixed

View, upload, resize to 500×500, replace or remove. Embeds clean JPEG/PNG via Pillow + mutagen so your DAP isn’t choking.

◎

Dry run is default

Preview what would be removed. Nothing touches disk until you disable dry run. Safe by design — dry_run=True.

⬢

Native desktop

Built with PySide6. No browser, no server. QThread workers keep the UI responsive while scanning.

◇

Human-readable tags

No ©ART nonsense. Maps aART → albumartist etc. in metadata.py. Add a tag once in tags.py and it appears everywhere.

FAQ & gotchas

macOS says the app is damaged / not verified?

It’s unsigned (no Apple notarization yet). Right-click the .app → Open → confirm. Or System Settings → Privacy & Security → Allow. After that it opens normally.

Will it delete my files?

No. It only edits tags inside the file. Preview (dry run) is on by default — you see what would be removed before anything is written. Writes only when you explicitly clean.

What about Windows?

Windows build is under testing (Windows (Unstable)/). You can run from source today, or download the artifact from GitHub Actions. Releases will follow once DLL checks pass.

Which files are safe to ignore?

The scanner skips ._ resource forks and non-audio files. Only .flac .m4a .mp4 are touched. Everything else is left alone.
